## ② 修的过程中**我自己引入的 4 处新问题**（全部被机制抓出）

| 引入的问题 | 怎么发现的 |
|---|---|
| **`ancestorResolves` 从 bundle 目录自己开始 → 嵌套副本"自我确认"**（任何同 scope 的插件依赖都被误报） | 作者自建的 12 例验证矩阵（F5 对照项 ✗） |
| **别名目录没被读到**（只在 `@deepseek-ai/` 目录里找，`scope-copy/` 的 name 从未读） | 同一矩阵（C ✗） |
| **`topLines` 作用域错误导致整个 profile 段 P0 崩溃**（计数器写在块内、`else` 在块外） | 语料用例报 `P7/P15 undefined` |
| **语料用 `null` 表示空目录 → 驱动写文件时抛错** | 语料用例 1.6ms 即失败 |

**另有 3 次"Python 字符串里用直引号"导致的脚本语法错误**（编辑手法问题，见 §6 W2）——
它们不产生错误结论，但每次都要重来；已改用 `write` 工具落脚本文件而非内联。
